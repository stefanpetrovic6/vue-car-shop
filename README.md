# 🚗 Car Shop — Vue.js Application

A multi-page car dealership application built with Vue.js, featuring vehicle browsing,
detailed specifications, user authentication, and an admin management panel.


## ✨ Features

- **Vue Router** — Multi-page navigation between views
- **User Authentication** — Login/logout functionality managed via state
- **Admin Panel** — Privileged users can edit vehicle names and prices

## 🛠️ Tech Stack

- **Vue.js 3**
- **Vue Router** — Client-side routing
- **Vuex* — Global state management (auth)
- **REST API** — Vehicle data from https://testapi.io/api/stefanp1/resource/cars

## 🚀 Getting Started

```bash
git clone https://github.com/stefanpetrovic6/vue-car-shop
npm install
npm run serve
```
